# HR Analytics Dashboard

An end-to-end HR analytics portfolio project using **Power BI, Python, Pandas, and CSV data** to explore employee attrition, workforce demographics, compensation, performance, training, and employee trends.

## Project Overview

This project analyzes the IBM HR Analytics Employee Attrition dataset and presents the findings through an interactive Power BI dashboard supported by Python-based exploratory data analysis.

### Dashboard Pages
- **Overview** — workforce KPIs and overall HR trends
- **Attrition** — attrition patterns across departments, roles, overtime, job level, and other factors
- **Demographics** — employee distribution by age, gender, marital status, and related workforce segments
- **Compensation & Tenure** — income, job level, tenure, performance, and training-related analysis
- **Details** — detailed employee-level analysis

## Tools & Technologies

## Key HR Metrics & Analysis
- Employee count
- Attrition rate
- Attrition by department and job role
- Attrition by overtime and business travel
- Attrition by job level
- Monthly income and compensation patterns
- Employee tenure
- Demographic distribution
- Performance rating distribution
- Training activity
- Outlier analysis

## Files
- `HR Analytics Dashboard.pbix` — interactive Power BI dashboard
- `HR_Analytics.py` — Python EDA script
- `HR_Analytics(1).ipynb` — Jupyter Notebook analysis
- `HR_Analytics_Cleaned.csv` — cleaned dataset

## Dataset Limitations
The IBM HR Analytics dataset does not contain fields required for some common HR metrics such as time-to-hire, absenteeism rate, manager span of control, or compa-ratio. These metrics are therefore not presented as calculated measures in this project.

Demonstrates practical skills in **data cleaning, exploratory data analysis, HR analytics, data visualization, Power BI dashboard development, and communicating business insights**.
